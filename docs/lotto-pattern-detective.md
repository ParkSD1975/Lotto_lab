# 패턴 탐정 (Pattern Detective) 설계

## 개요

당첨번호 리스트에서 조건을 설정하면 해당 회차가 리스트업되고,
각 매칭 회차의 전후 회차(-2, -1, 0, +1)를 함께 조회하여
사람이 직접 패턴을 분석할 수 있는 인터랙티브 필터링 도구.

딥러닝이 결론을 내리는 게 아닌, **사람의 분석을 보조**하는 역할.

---

## 화면 구성

### 1. 조건 설정 영역 (상단)

**기본 조건**
- 번호 선택: 1~45 중 복수 선택 (AND / OR 선택)
- 회차 범위: 전체 / 최근 N회차 / 특정 회차 구간

**예시 조건**
```
번호 2 AND 번호 22 출현
회차 범위: 1000회차 이후
```

### 2. 결과 리스트 (메인)

조건에 맞는 회차를 기준으로 전후 회차를 함께 표시.

| 회차 | 구분 | n1 | n2 | n3 | n4 | n5 | n6 | 보너스 |
|------|------|----|----|----|----|----|----|--------|
| 248  | -2   | 3  | 15 | 27 | 33 | 41 | 44 | 7      |
| 249  | -1   | 7  | 18 | 22 | 31 | 38 | 45 | 2      |
| **250**  | **0 ★** | **2**  | **11** | **22** | **34** | **37** | **42** | **5** |
| 251  | +1   | 5  | 13 | 19 | 28 | 36 | 43 | 9      |
|      |      |    |    |    |    |    |    |        |
| 398  | -2   | 1  | 9  | 18 | 26 | 35 | 40 | 11     |
| 399  | -1   | 4  | 16 | 22 | 29 | 33 | 41 | 7      |
| **400**  | **0 ★** | **2**  | **8**  | **22** | **27** | **38** | **44** | **3** |
| 401  | +1   | 6  | 11 | 20 | 31 | 37 | 45 | 14     |

- `0 ★` 행: 조건 충족 회차 (강조 표시)
- 매칭 건수 표시: "총 N건 발견"

### 3. 전후 회차 범위 설정

사용자가 직접 조정 가능:

```
표시 범위:  [ -2 ] ~ [ +1 ]  회차
```

설정 옵션 예시:
- `-1 ~ +1` (앞뒤 1회차)
- `-2 ~ +2` (앞뒤 2회차)
- `-5 ~ 0` (이전 5회차만)
- `0 ~ +3` (이후 3회차만)
- 직접 입력

## 조건 설정 상세

### 기본 조건 타입

| 조건 타입 | 예시 |
|-----------|------|
| 특정 번호 포함 | 2번 AND 22번 |
| 끝수 조건 | 끝수 2 포함 2개 이상 |
| 총합 범위 | 총합 140~160 |
| 홀짝 비율 | 홀수 4개 이상 |
| 번호대 조건 | 40번대 2개 이상 |
| AC값 조건 | AC값 8 이상 |
| 연번 포함 | 연번 1쌍 이상 |
| 이월수 | 직전 회차 번호 포함 |

### 복합 조건

AND / OR / NOT 조합 가능:
```
(2번 OR 22번) AND 총합 140~160 AND 홀수 3개
```

## 자동 계산 컬럼 (선택 표시)

리스트에 추가로 표시할 수 있는 파생 지표:

| 컬럼 | 설명 |
|------|------|
| 총합 | n1~n6 합계 |
| 끝수합 | 1의 자리 합 |
| AC값 | 산술 복잡도 |
| 홀/짝 | 홀수 개수 : 짝수 개수 |
| 저/고 | 저번호(1~22) : 고번호(23~45) |
| 이월수 | 직전 회차와 겹치는 번호 수 |
| 이웃수 | 직전 회차 ±1 번호 수 |
| 연번 쌍 | 연속번호 쌍 수 |

## 통계 패널 (리스트 우측 또는 하단)

매칭된 0회차 N건에 대한 자동 통계:

### 번호별 출현 빈도
매칭된 0회차들에서 각 번호(1~45)가 몇 번 나왔는지 빈도표 + 히트맵

### +1회차 출현 빈도
조건 충족 다음 회차에서 자주 나온 번호 → 사람이 "다음에 나올 번호" 힌트로 활용

### 공통 패턴 요약
```
매칭 12건 분석:
- 0회차 평균 총합: 152.3
- +1회차에서 15번 출현: 7/12건 (58%)
- 0회차 이후 +1회차 총합이 낮아지는 경향: 9/12건 (75%)
```

### 샘플 수 경고
- 매칭 건수 10건 미만: "⚠ 샘플 부족 — 통계적 신뢰도 낮음"
- 매칭 건수 20건 이상: "✓ 분석 가능"
- 매칭 건수 50건 이상: "✓✓ 높은 신뢰도"

## 데이터 쿼리 구조 (Supabase SQL)

```sql
-- 조건: 특정 번호 2개 동시 포함된 회차 조회
WITH matched AS (
  SELECT draw_no, draw_date
  FROM draws
  WHERE lottery_id = :lottery_id
    AND :num1 IN (n1,n2,n3,n4,n5,n6)
    AND :num2 IN (n1,n2,n3,n4,n5,n6)
    AND draw_no >= :from_no
),
range_nos AS (
  SELECT
    m.draw_no AS base_no,
    m.draw_no + offset AS target_no,
    offset AS relative_pos
  FROM matched m
  CROSS JOIN (VALUES (-2),(-1),(0),(1)) AS t(offset)
)
SELECT
  r.base_no,
  r.relative_pos,
  d.draw_no,
  d.draw_date,
  d.n1, d.n2, d.n3, d.n4, d.n5, d.n6, d.b1,
  d.sum, d.odd_count, d.ac, d.consecutive_pairs
FROM range_nos r
JOIN draws d ON d.draw_no = r.target_no
  AND d.lottery_id = :lottery_id
ORDER BY r.base_no, r.relative_pos;
```

## UI 인터랙션 흐름

```
1. 로또 선택 (한국 로또 6/45 등)
2. 조건 입력 (번호, 범위 등)
3. [검색] 클릭
4. 결과 리스트 표시 (0회차 강조)
5. 전후 범위 슬라이더로 -2~+1 조정
6. 우측 통계 패널 자동 업데이트
7. 원하는 컬럼(총합, AC값 등) 토글 ON/OFF
8. 결과 CSV 내보내기 (선택)
```
