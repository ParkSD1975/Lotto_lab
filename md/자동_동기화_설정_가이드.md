# 🔄 로또 데이터 자동 동기화 설정 가이드

## 📋 3가지 방법

1. **Python 스케줄러** (간편, 프로그램 실행 중에만 작동)
2. **Windows 작업 스케줄러** (추천, 가장 안정적)
3. **백그라운드 서비스** (고급, 항상 실행)

---

## 1️⃣ Python 스케줄러 (APScheduler)

### 설치
```powershell
pip install apscheduler tenacity
```

### 실행
```powershell
python auto_sync_scheduler.py
```

### 동작 방식
- **매주 토요일 21:30** - 추첨 직후 자동 동기화
- **매주 일요일 09:00** - 확인용 재동기화
- 로그 파일: `lotto_sync.log`

### 장점
✅ 설정 간단
✅ 로그 파일 자동 생성
✅ 실시간 콘솔 출력

### 단점
❌ 프로그램을 계속 실행 상태로 두어야 함
❌ PC 종료 시 작동 안 함

## 2️⃣ Windows 작업 스케줄러 ⭐ 추천

### 설정 방법

#### A. GUI로 설정 (쉬움)

1. **작업 스케줄러 열기**
   - `Win + R` → `taskschd.msc` 입력

2. **기본 작업 만들기** 클릭

3. **이름 및 설명**
   - 이름: `로또 데이터 자동 동기화`
   - 설명: `매주 토요일 밤 동행복권에서 최신 데이터 가져오기`

4. **트리거**
   - 매주 선택
   - 요일: 토요일
   - 시간: 21:30

5. **작업**
   - 프로그램 시작 선택
   - 프로그램/스크립트:
     ```
     C:\Users\psdet\AppData\Local\Programs\Python\Python312\python.exe
     ```
   - 인수 추가:
     ```
     sync_lotto_data_improved.py --update
     ```
   - 시작 위치:
     ```
     C:\Users\psdet\Desktop\디자인
     ```

6. **마침** 클릭

#### B. PowerShell로 설정 (고급)

```powershell
# 작업 생성
$action = New-ScheduledTaskAction -Execute "python.exe" `
    -Argument "sync_lotto_data_improved.py --update" `
    -WorkingDirectory "C:\Users\psdet\Desktop\디자인"

$trigger = New-ScheduledTaskTrigger -Weekly -DaysOfWeek Saturday -At 21:30

$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries

Register-ScheduledTask -TaskName "로또데이터자동동기화" `
    -Action $action `
    -Trigger $trigger `
    -Settings $settings `
    -Description "동행복권에서 최신 로또 데이터 자동 가져오기"
```

### 확인 방법
```powershell
# 등록된 작업 확인
Get-ScheduledTask -TaskName "로또데이터자동동기화"

# 수동 실행 (테스트)
Start-ScheduledTask -TaskName "로또데이터자동동기화"

# 마지막 실행 결과 확인
Get-ScheduledTaskInfo -TaskName "로또데이터자동동기화"
```

### 장점
✅ PC 시작 시 자동 실행 가능
✅ 백그라운드 실행
✅ 오류 발생 시 재시도 설정 가능
✅ Windows 기본 기능

### 단점
❌ 설정이 다소 복잡
❌ 로그 확인이 번거로움

## 3️⃣ 백그라운드 서비스 (NSSM)

### 설치

1. **NSSM 다운로드**
   ```powershell
   # Chocolatey로 설치
   choco install nssm

   # 또는 수동 다운로드
   # https://nssm.cc/download
   ```

2. **서비스 등록**
   ```powershell
   nssm install LottoSync "C:\Users\psdet\AppData\Local\Programs\Python\Python312\python.exe" "C:\Users\psdet\Desktop\디자인\auto_sync_scheduler.py"
   ```

3. **서비스 시작**
   ```powershell
   nssm start LottoSync
   ```

### 관리 명령어
```powershell
# 상태 확인
nssm status LottoSync

# 중지
nssm stop LottoSync

# 재시작
nssm restart LottoSync

# 제거
nssm remove LottoSync confirm
```

### 장점
✅ Windows 시작 시 자동 실행
✅ 항상 백그라운드 실행
✅ 서비스 관리 편리

### 단점
❌ 추가 프로그램 설치 필요
❌ 설정 복잡

python sync_lotto_data_improved.py --latest
