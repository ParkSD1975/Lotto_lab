Q: "새로운 탭이 안 보여요"
A: 1) 백엔드가 제대로 시작되었는지 확인
   2) 브라우저 캐시 삭제 (Ctrl+Shift+Del) + 새로고침 (F5)
   3) 개발자도구 (F12) > Console에서 에러 확인

Q: "상태분석 탭의 데이터가 안 보여요"
A: API 응답이 정상인지 확인
   개발자도구 (F12) > Network > /analysis 요청 확인

Q: "9궁분석이 작동 안 해요"
A: 백엔드 로그 확인
   "python main.py" 실행 후 콘솔에서 에러 메시지 확인
