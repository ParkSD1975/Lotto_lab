⏳ Phase 1.5: Hot/Neutral/Cold 분석 (다음)

⏳ Phase 2: 9궁(9-Palace) 분석 (이번주)
  - 45개 번호를 3×3 격자(9개 영역)로 분류
  - 영역별 불균형 분석
  - 최근 50회 빈도 분석
  - 예상 시간: 1.5시간

⏳ Phase 3: 로또용지(Lottery Sheet) 평가 (다음주)
  - 사용자 저장 조합 개별 평가
  - 각 조합별 5모델 점수 계산
  - 필터 준수도 평가 (%)
  - 예상 시간: 1.5시간

Q: "새로운 필터가 안 보여요"
A: 1) 백엔드가 제대로 재시작되었는지 확인 (python main.py 실행 중인가?)
   2) 브라우저 캐시 삭제 (Ctrl+Shift+Del) 후 새로고침
   3) 개발자도구(F12) > Console에서 에러 확인

Q: "API 응답이 없어요"
A: 1) 백엔드 서버가 실행 중인가 확인 (포트 8000 확인)
   2) 개발자도구(F12) > Network탭에서 /api/deep-analysis 요청 확인
   3) 백엔드 콘솔 로그 확인

Q: "커스텀 그룹이 없어서 추천이 안 보여요"
A: 커스텀 그룹을 생성해야 추천값이 나옵니다.
   관리자 또는 설정 페이지에서 커스텀 그룹 추가 후 확인
