## 📊 15개 필터 한눈에 보기

### 기본 필터 (6개)
- **총합**: 6개 번호의 합계
- **AC값**: 번호 간격의 복잡도
- **홀짝**: 홀수/짝수 비율
- **저고**: 저번호/고번호 비율
- **끝수합**: 끝자리 수의 합
- **AC값**: 번호간 차이 종류

### 수학 필터 (5개)
- **소수**: 소수 포함 개수
- **합성수**: 합성수 포함 개수
- **제곱수**: 제곱수 포함 개수
- **삼각수**: 삼각수 포함 개수
- **동형수**: 11,22,33,44 포함 개수

### 배수 필터 (4개)
- **3배수**: 3의 배수 개수
- **4배수**: 4의 배수 개수
- **5배수**: 5의 배수 개수
- **배수외**: 배수 아닌 수 개수

## ✨ 주요 기능

### 1. 모든 필터에 모델별 분석
✅ 15개 필터 모두 5개 모델의 분석 제시
✅ 각 모델의 예상 범위 (min~max)
✅ 분석 근거 텍스트

### 2. 커스텀 그룹 추천
✅ 그룹 생성 시 자동으로 필터 추천
✅ 15개 필터 모두에 대한 최적값 제시
✅ 그룹 특성에 맞춘 가이드

### 3. 모델별 색상 구분
```
🔷 LSTM (인디고)      - 시계열 분석
🔷 XGBoost (파랑)     - 통계 기반
🔷 CNN (빨강)         - 공간 기반
🔷 Transformer (초록) - 관계 기반
🔷 Markov (시안)      - 상태 기반
```

## 🎯 필터 분석 팁

### 초보자
**추천 필터 3개**: 총합, 홀짝, 저고
- 이 3개 필터로 기본 조합 만들기
- 권장값: 총합 100~180, 홀짝 3:3, 저고 3:3

### 중급자
**추천 필터 6개**: 위 3개 + AC값, 끝수합, 연속
- 조합의 정밀도 향상
- 모델 간 합의도 확인

### 고급자
**모든 15개 필터 활용**
- 배수 필터로 세밀한 조합
- 수학 성질 필터로 특수 전략
- 모델 분석을 통한 최적화

---

## 🔍 모델별 역할

### LSTM (시계열)
- 최근 출현 빈도 반영
- 주기적 변화 감지
- 최신 트렌드 중심

### XGBoost (통계)
- 과거 빈도 기반
- 통계적으로 검증된 패턴
- 안정적인 예측

### CNN (공간)
- 번호의 공간적 분포
- 그룹화된 패턴
- 이웃 번호 관계

### Transformer (관계)
- 복잡한 패턴 인식
- 시간적 관계 분석
- 주기 패턴 감지

### Markov (상태)
- 상태 전이 확률
- 상태 변화 추적
- 확률 기반 분석

효과: 안정성-수익성 균형

## ❓ FAQ

### Q: 어떤 필터부터 시작해야 하나?
**A**: 총합, 홀짝, 저고 3개만 먼저 익히세요. 이 3개로도 충분합니다.

### Q: 5개 모델을 모두 봐야 하나?
**A**: 여러 모델이 같은 범위를 추천하면 신뢰도 높습니다. 모델 간 합의도를 확인하세요.

### Q: 커스텀 그룹을 만들면?
**A**: 자동으로 15개 필터의 추천값이 표시됩니다. 이를 참고해 조합을 완성하세요.

### Q: 필터가 안 보이면?
**A**: 브라우저 캐시 삭제 (Ctrl+Shift+Del) + 새로고침 (F5)

### Q: API 오류가 나면?
**A**: 백엔드 재시작 (python main.py)
