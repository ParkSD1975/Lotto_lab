### 🚫 [보존 지침 - 절대 수정 금지]
기존 코드를 분석해서 다음 부분은 **단 한 줄도 변경하거나 삭제하지 마.** (그대로 유지)
1. **HTML 레이아웃 전체**: 헤더, 사이드바, `chart-container`, `drawsList` 테이블 구조, 모달 창 등.
2. **스타일 & 외부 리소스**: Tailwind CSS 클래스, `<link>` 태그, `<style>` 태그 내부 CSS.
3. **차트 설정(Chart.js)**: `renderChart` 함수 내부의 차트 옵션, 데이터셋 구성, 색상 설정.
4. **유틸리티 함수**: `updateFilters`, `toggleFilterApply`, `saveFilterSettings`, `loadFilterSettings`.

### ✅ [수정 지침 - 여기만 교체]
오직 **`<script>` 태그 내부의 데이터 로딩 및 조회 로직**만 다음 4단계로 재작성해:

#### 1. 전역 변수 및 캐시 설정
- `allData` (당첨번호) 외에, DB 데이터를 저장할 `featuresMap`을 추가해.
- **구조 차이점**: `hot_cold.html`은 `Array`를 저장했지만, 여기서는 **단일 값(Integer)**을 저장해.
  ```javascript
  let featuresMap = new Map(); // Key: round(회차), Value: ac_value(정수)
#### 2. 데이터 로딩 최적화 (Bulk Fetch)
DOMContentLoaded 내부를 수정하여 Promise.all로 병렬 로딩해:
lotto_draws (당첨 번호)
ac_value_by_round (AC값 데이터 테이블)
로딩된 AC값 데이터를 featuresMap에 round를 Key로 하여 매핑해.
loadingOverlay 제어 코드를 추가해 (시작 시 표시, 종료 시 숨김).
#### 3. 분석 함수 교체 (Hybrid Logic)
기존 getACValue 함수를 getACValueLegacy로 이름 변경하여 백업해.
새로운 getACValue 함수 작성:
JavaScript

function getACValue(draw) {
    // 1. DB 캐시(featuresMap)에 있으면 즉시 리턴 (O(1))
    if (featuresMap.has(draw.round)) return featuresMap.get(draw.round);
    // 2. 없으면 백업해둔 Legacy 함수로 직접 계산
    return getACValueLegacy(draw.numbers);
}
#### 4. 렌더링 루프 동기화 (Sync Rendering)
renderDrawsList 함수에서 await 키워드를 모두 제거해.
위에서 만든 getACValue가 동기 함수이므로, 이제 await 없이 즉시 값을 가져와서 HTML을 그릴 수 있어. (N+1 문제 해결)
