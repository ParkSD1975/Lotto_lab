# 🔧 API 연동 문제 해결 가이드

## 📊 발견된 문제점

### 1. ❌ 테이블 이름 불일치
- **app.py**: `lotto_history` 사용
- **winning-numbers.html**: `lotto_draws` 사용
- **실제 Supabase**: `lotto_draws` 테이블만 존재

**해결:** ✅ app.py를 `lotto_draws`로 수정 완료

---

### 2. ❌ Edge Function 이름 불일치
- **HTML에서 호출**: `sync-lotto`
- **실제 배포된 함수**: `analyze-lotto` (AI 분석용)
- **새로 만든 함수**: `sync-lotto-data` (아직 배포 안됨)

**해결:** ✅ HTML을 `sync-lotto-data`로 수정 + 배포 필요

---

### 3. ❌ 데이터 스키마 불일치
- **app.py**: `num1, num2, num3...` 형식으로 접근 시도
- **실제 테이블**: `numbers` 배열로 저장됨

**해결:** ✅ app.py를 배열 직접 사용으로 수정 완료

---

## 🎯 Edge Function 배포 (선택사항)

**"최신 데이터" 버튼이 자동으로 작동하게 하려면:**

```bash
# 1. Supabase CLI 설치
npm install -g supabase

# 2. 로그인
supabase login

# 3. 프로젝트 연결 (프로젝트 ID 필요)
supabase link --project-ref dkcflmyoscudawleglzb

# 4. Edge Function 배포
supabase functions deploy sync-lotto-data

# 5. 환경 변수 설정 (Supabase 대시보드에서)
# SUPABASE_URL: https://dkcflmyoscudawleglzb.supabase.co
# SUPABASE_SERVICE_ROLE_KEY: (Settings > API에서 확인)
```

**배포 완료 후:**
- "최신 데이터" 버튼이 자동으로 작동합니다
- Python 스크립트 없이도 데이터 업데이트 가능
