📅 프로젝트명: AI Deep Learning Lab 구축
1단계: 페이지 기획 및 데이터 설계 (Blueprint)
목표: 단순 채팅창이 아닌, 데이터 중심의 'AI 대시보드' 형태로 재구축합니다.

페이지 역할 정의:

기존: "AI에게 물어보면 텍스트로 답해줌" (Chatbot)

변경: "AI가 학습한 결과를 그래프와 수치로 먼저 보여주고, 이유를 설명함" (Dashboard)

핵심 데이터 섹션 (UI 구성안):

AI 모델 신뢰도 (Confidence Score): 이번 회차 예측의 정확도 예상치 (예: "LSTM 모델 신뢰도 87%")

제외수/고정수 추천 (Filter): 딥러닝이 강력하게 비추천(제외)하거나 추천(고정)하는 번호 리스트.

심층 분석 리포트: 기초 분석(홀짝, 합계 등)과 커스텀 분석(사용자 설정)을 AI가 재해석한 결과.

Final 조합 추천: 모든 모델의 가중치를 합산하여 도출된 최종 5~10게임 추천.

2단계: 프론트엔드 UI 개발 (HTML/JS)
목표: ai_analysis.html (가칭) 페이지를 신설하거나 기존 페이지를 전면 수정합니다.

주요 UI 컴포넌트:

히트맵(Heatmap): 1~45번 번호별 AI 추천 점수(0~100점) 시각화.

레이더 차트: 회차별 모델 성능 비교 (XGBoost vs LSTM vs Markov).

카드 UI: 추천 필터(예: "이번 주는 합계 120~150 구간 유력") 자동 생성.

3단계: 백엔드 API 연동 (Python/LangChain)
목표: 이미 구축된 langchain-backend와 이 페이지를 전용으로 연결합니다.

신규 API 엔드포인트 활용:

/api/predictions/{round}: 다음 회차 예측 데이터 전체 수신.

/api/explain: 특정 번호를 왜 추천/제외했는지 근거 요청 (XAI).

데이터 흐름:

페이지 로드 시: 백엔드에서 **'미리 계산된 예측값(Prediction Table)'**을 즉시 호출 (로딩 속도 0.5초 이내 목표).

상세 클릭 시: "왜 이 번호야?" → 실시간으로 AI에게 설명 요청.

4단계: '기초+커스텀' 데이터 통합 로직 구현
목표: 딥러닝 모델이 사용자의 기존 분석 패턴을 학습하도록 연결합니다.

앙상블(Ensemble) 가중치 적용:

사용자가 '커스텀 분석'에서 자주 쓰는 패턴(예: 회귀 분석)이 있다면, 해당 패턴에 가중치를 더 주는 로직 추가.

구현 방법: 프론트엔드에서 사용자의 선호 분석 데이터를 JSON으로 묶어 백엔드 예측 요청 시 함께 전송 (custom_bias 파라미터).

5단계: 배포 및 시각화 고도화
추천 필터 자동 생성: AI가 예측한 결과를 바탕으로 "이 필터를 쓰세요"라고 역으로 제안하는 기능.

예: "AI가 분석해보니 이번엔 '소수 2개 이상' 필터가 적중 확률 92%입니다. 적용하시겠습니까?" (버튼 클릭 시 필터 적용)
