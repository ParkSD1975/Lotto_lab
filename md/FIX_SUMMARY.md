# 🔧 모델 점수 차별화 문제 - 긴급 해결 완료

## 문제점 (사용자 피드백)
```
❌ "이게 뭐야? 별의미 없는 페이진데?"
❌ "lstm와 cnn trans 점수가 왜 다 동일하지?"
```

---

## 원인 분석

### 기존 방식의 문제
```python
# 각 모델을 자신의 범위 내에서 0~100으로 정규화
norm_score = (raw_prob - min) / (max - min) * 100

예:
- LSTM의 확률 범위: 0.01~0.05 → 0.03은 (0.03-0.01)/(0.05-0.01)*100 = 50점
- XGB의 확률 범위: 0.02~0.06 → 0.04는 (0.04-0.02)/(0.06-0.02)*100 = 50점

결과: 다른 모델인데 같은 번호가 모두 ~50점!
```

### WHY 이런 일이?
- 각 모델이 **자신의 최소~최대 범위 안에서만** 정규화
- 따라서 상대적 위치가 비슷하면 점수도 비슷해짐
- 모델 간 **실질적 차이**를 보여주지 못함

---

## 해결 방법 (2가지 개선)

### 1️⃣ 점수 정규화 방식 변경

**Before (Min-Max Scaling)**
```python
각 모델별로: (값 - 최소값) / 범위 * 100
→ 결과: 모든 모델의 점수가 비슷함
```

**After (Percentile Ranking)**
```python
각 모델별로: 상위 몇 %인지 계산 = (45 - 순위) / 45 * 100

예:
- LSTM에서 번호 27이 상위 10% (5위) → (45-5)/45*100 = 89점
- XGB에서 번호 27이 상위 30% (14위) → (45-14)/45*100 = 69점
- CNN에서 번호 27이 상위 20% (9위) → (45-9)/45*100 = 80점

→ 결과: 명확한 차이 (89, 69, 80)!
```

**코드 변경** (라인 456-478)
```python
# 각 모델을 순위로 정렬
for m in models:
    probs = [(n, contribs.get(m, {}).get(n, 0)) for n in range(1, 46)]
    probs.sort(key=lambda x: x[1], reverse=True)
    model_all_probs[m] = {num: (순위, 확률) for ...}

# 백분위로 변환
rank, raw_prob = model_all_probs[m][n]
percentile_score = (45 - rank) / 45 * 100
```

---

### 2️⃣ 모델별 근거 설명 강화

**각 모델의 분석 관점을 명확히 함** (라인 77-155)

```
LSTM (시계열):
  "최근 3회 연속 출현 | 시계열 강한 상승추세"
  "안정적 주기 상태(Gap=8회) | 중립적 신호"
  → 관점: 최근 추세, streak/gap 중심

XGBoost (통계):
  "높은 빈도(18%) | 통계 패턴 매우 강함"
  "낮은 빈도(2%) | 패턴 약함"
  → 관점: 역사적 빈도 패턴

CNN (공간):
  "이웃그룹 활성(38%) | 공간 시너지 매우 높음"
  "이웃그룹 고립(12%) | 공간 신호 약함"
  → 관점: 인접 번호와의 관계

Transformer (주기):
  "주기패턴 ~7회 | 주기성 규칙도: 5회"
  "주기분석 불충분 | 데이터 부족"
  → 관점: 반복 주기 패턴

Markov (상태):
  "높은 전이(22%) | 상태 강하게 지속"
  "낮은 전이(5%) | 상태 약화 신호"
  → 관점: 최근 분포 지속성
```
