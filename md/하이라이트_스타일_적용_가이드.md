# 하이라이트 스타일 및 디자인 표준화 가이드

기본 분석 페이지(`total_sum`, `tail_digit`, `ac_value` 등)의 디자인을 통일하고 보라색 하이라이트 스타일을 적용하기 위한 최신 가이드입니다.

---

## 📋 통합 표준 프롬프트 (강력 추천) ⭐

```
@[파일명.html] 이 파일의 디자인을 total_sum.html 및 ac_value.html 스타일로 통합해줘:

1. 하이라이트 스타일 (보라색 테마)
   - 행 배경색: #F3E8FF (옅은 보라색) - **회차, 당첨번호 포함 전체 셀 적용**
   - 선택 행 배경색: #E9D5FF (진한 보라색)
   - 왼쪽 테두리: 4px solid #7C3AED (딥퍼플) 추가 (첫 번째 셀에 적용)
   - **흔들림 방지(Shaking Fix)**: 기본 상태(`tr td:first-child`)에 `border-left: 4px solid transparent`를 미리 적용하여 하이라이트 시 화면 밀림 방지
   - 행 hover 효과(bg-gray-50 등) 및 transition-colors 제거 (하이라이트 시 색상 고정)

2. "조합 필터" 섹션 재구성
   - 제목을 "조합 필터"로 변경
   - 입력 필드 레이블을 "Min", "Max"로 변경하고 굵게 표시
   - 레이아웃: "필터 적용" 토글은 [좌측 하단], "최근 10회차 필터 적용" 버튼은 [우측 하단]에 배치

3. 리스트 디자인 (테이블화 및 통합형 디자인)
   - div 기반 리스트를 table 구조로 변경 하여 정렬 및 성능 최적화
   - 헤더(thead): bg-[#1e293b], sticky top-0, 텍스트 흰색
   - 회차 열(Round): w-20(80px), whitespace-nowrap 적용 (글자 내려남 방지)
   - 컨테이너: 리스트를 감싸는 흰색 카드 배경(bg-white border shadow-sm)을 제거하고 투명하게 처리 (**Integrated Look**)
   - **섹션 헤더 표준화**: 테이블 상단에 제목(h3, text-lg font-bold)과 안내 문구(p, text-sm text-gray-600)를 배치하여 상단 디자인과 통일성 유지

4. 불필요한 스타일 제거
   - **오렌지 테두리 제거**: 예전에 사용하던 상/하단 오렌지색 테두리(`.top-border`, `.bottom-border`)를 완전히 제거하고 배경색으로만 구분
   - **스크롤 방지**: 행 클릭 시 `scrollIntoView` 기능을 제거하여 화면이 튀는 현상 방지

5. 기능 고도화
   - **하이라이트 토글(Toggle)**: 클릭된 행이 이미 하이라이트 상태이거나 동일 회차일 경우, 하이라이트를 해제(Reset)하는 로직 포함
   - 최근 10회차 필터 버튼에 토글(On/Off) 기능 추가
   - 활성화 시: 보라색 그라데이션 버튼 + "필터 해제" 텍스트
   - 비활성화 시: 파란색 그라데이션 버튼 + "필터 적용" 텍스트

6. 리스트 필터링 정책 (Unfiltered List) ⭐
   - 사용자가 조합 필터를 설정하더라도, **하단 리스트는 무조건 전회차가 조회**되어야 합니다.
   - 필터링은 조합기에 적용될 설정값을 저장하는 용도이며, 리스트 뷰를 가리는 용도가 아닙니다.
   - 코드 예시: `.filter(d => checkDrawFilter(d))` 부분을 제거하고 전체 데이터를 렌더링하세요.
```

## 🎨 디자인 명세 (Design Tokens)

### 1. 색상 (Colors)
- **일반 하이라이트**: `#F3E8FF` (옅은 보라색)
- **선택 하이라이트**: `#E9D5FF` (진한 보라색)
- **강조 테두리/포인트**: `#7C3AED` (딥퍼플)
- **테이블 헤더**: `#1e293b` (다크 네이비)
- **활성 버튼**: `bg-gradient-to-r from-purple-500 to-purple-700`
- **비활성 버튼**: `bg-gradient-to-r from-blue-500 to-indigo-600`

### 2. 레이아웃 (Layout)
- **회차 열 폭**: `w-20` (약 80px) 필수 사용
- **텍스트 줄바꿈**: `whitespace-nowrap` 필수 적용
- **하이라이트 선**: `border-left: 4px` (왼쪽 전체) 적용
- **레이아웃 안정성**: 투명 테두리(`border-left: 4px solid transparent`)를 통한 Shaking Fix 필수 적용

## 💡 성능 및 UX 팁

### **성능 최적화**
- `querySelectorAll` 사용 시 전체 DOM이 아닌 `.row-highlight` 등 특정 클래스만 타겟팅하세요.
- 불필요한 `transition-colors`는 리스트 렌더링 성능을 저하시킬 수 있으므로 제거를 권장합니다.

### **상황별 프롬프트**
- **디자인만 바꿀 때**: "기능은 유지하고 하이라이트 색상과 테이블 레이아웃만 ac_value.html 스타일로 바꿔줘"
- **특정 열 고정**: "회차 열이 내려가지 않게 w-20과 whitespace-nowrap을 꼭 적용해줘"
- **필터 배치 수정**: "필터 적용 토글은 왼쪽 아래, 최근 10회차 버튼은 오른쪽 아래로 옮겨줘"
