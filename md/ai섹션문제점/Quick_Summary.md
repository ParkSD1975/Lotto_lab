## 🔴 Critical Issues (즉시 해결 필요)

### Issue 1️⃣: 프롬프트 포맷 모순
```
상황:     AI 프롬프트가 {{key:value}} 태그 + JSON을 동시에 요구
영향:     응답 파싱 실패율 55%
심각도:   🔴 CRITICAL
해결시간: 2시간
```

**현재 코드:**
```javascript
2. 중요 키워드는 {{trend:내용}}, {{pattern:내용}} 태그로 감싸시오.
4. 오직 순수 JSON 포맷 {"response": "..."} 으로만 응답하시오.
```

**문제:** JSON 안에 {{}} 태그가 들어가면 JSON 파싱 실패!

**해결안:**
```javascript
Response MUST be valid JSON:
{
  "analysis": "내용",
  "trends": ["상승세"],
  "patterns": ["연속출현"]
}
```

### Issue 2️⃣: XSS 보안 취약점
```
상황:     응답 파싱 실패 시 원본 데이터를 그대로 사용
코드:     } catch(e) { content = data; }
영향:     HTML/JS 인젝션 공격 가능
심각도:   🔴 CRITICAL
해결시간: 1시간
```

**위험 시나리오:**
```javascript
// 공격자가 다음을 응답으로 전송:
<img src=x onerror="alert('XSS')">

// 현재 코드는 그대로 렌더링:
container.innerHTML = `<div>${data}</div>`  // ❌ 위험!
```

**해결안:**
```javascript
container.textContent = data;  // ✅ 안전 (HTML 태그 무시)
```

### 2. 보안 강화

❌ **현재 (위험)**
```javascript
catch (err) {
    content = data;  // XSS 위험!

container.innerHTML = content;
```

✅ **개선안 (안전)**
```javascript
// 방법 1: textContent 사용
container.textContent = data;

// 방법 2: DOMPurify 사용
container.innerHTML = DOMPurify.sanitize(data);

// 방법 3: 스키마 검증 후 사용
if (validateSchema(data)) {
    container.innerHTML = sanitizeHtml(data);
```

```javascript
async function submitModalFollowUp() {
```

✅ **개선안 (메모리 있음)**
```javascript
class SmartChatBot {
    constructor(userId) {
        this.userId = userId;
        this.messages = [];
    }
    
    async addUserMessage(content) {
        this.messages.push({ role: 'user', content });
        await this.saveToDB();
        
        // 이전 메시지 포함한 컨텍스트 생성
        const context = this.buildContext();
        return await this.getAIResponse(context);
    }
    
    buildContext() {
        const recent = this.messages.slice(-5);
        return recent.map(m => `${m.role}: ${m.content}`).join('\n');
    }
}
```
