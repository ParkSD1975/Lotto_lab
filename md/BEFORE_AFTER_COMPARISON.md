### 기술 해결
```
Percentile Ranking 방식:

LSTM:
  모든 45개 번호를 확률로 정렬
  번호 27이 5위 (상위 10%)
  점수: (45 - 5) / 45 * 100 = 89점

XGBoost:
  모든 45개 번호를 확률로 정렬
  번호 27이 25위 (상위 56%)
  점수: (45 - 25) / 45 * 100 = 44점

결과: LSTM 89, XGBoost 44 → 명확한 차이!
      (각 모델이 어디를 강조하는지 보임)
```

## 핵심 개선 사항

### 1. 점수 차별화

| 항목 | Before | After |
|------|--------|-------|
| **점수 범위** | 71~73 | 40~85 |
| **표준편차** | ~0.7 | ~17.5 |
| **최대-최소** | 2점 | 45점 |
| **차이 확인** | 거의 없음 | 매우 명확 |

### 2. 근거 설명

**Before:**
```
LSTM: "안정적 주기 상태(Gap=8회)"
XGB:  "중간 빈도(8%)"
CNN:  "이웃 그룹 평가 중"
→ "관점이 뭐가 다른지 모름"
```

**After:**
```
LSTM: "최근 3회 연속 출현 | 시계열 강한 상승추세"
      → 관점: 시계열 추세, streak/gap 중심

XGB:  "낮은 빈도(8%) | 패턴 약함"
      → 관점: 통계적 빈도, 역사적 패턴

CNN:  "이웃그룹 고립(12%) | 공간 신호 약함"
      → 관점: 공간적 그룹화, 이웃 번호 관계

Transformer: "주기패턴 ~6회 | 주기성 규칙도: 4회"
             → 관점: 주기성, 반복 패턴

Markov: "낮은 전이(5%) | 상태 약화 신호"
        → 관점: 상태 지속성, 최근 분포

→ "5가지 명확히 다른 관점!"
```

### 3. 시각화 개선

**Before:**
```
모든 모델의 게이지가 비슷한 길이
사용자: "뭐가 다른지 구분이 안 됨"
```

**After:**
```
각 모델의 게이지 길이가 다름
- LSTM: 매우 김 (89점)
- XGB: 짧음 (44점)
- CNN: 중간 (60점)
- Trans: 김 (78점)
- Markov: 짧음 (40점)

사용자: "아! LSTM과 Transformer는 추천, XGB와 Markov는 회의적이네"
```
