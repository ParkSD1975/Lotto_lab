## 현재 상태

### ✅ 이미 구현된 것 (12개 필터)
```
기본 필터 (4개):
  - sum: 6개 번호의 합계
  - ac: 번호 간 차이 종류 개수
  - odd: 홀수 개수
  - high: 고번호(23~45) 개수

수학적 필터 (5개):
  - tail_sum: 끝자리 합
  - prime: 소수 개수
  - composite: 합성수 개수
  - square: 제곱수 개수
  - triangular: 삼각수 개수

패턴 필터 (3개):
  - consecutive: 연속 쌍 개수
  - twin: 쌍둥이 수(11,22,33,44) 개수
  - mul3: 3의 배수 개수
```

### ❌ 누락된 것 (사용자 요구)
```
배수 필터:
  ❌ 4배수 (mul4): 4, 8, 12, 16, 20, 24, 28, 32, 36, 40, 44
  ❌ 5배수 (mul5): 5, 10, 15, 20, 25, 30, 35, 40, 45
  ❌ 배수외 (non_mul): 특정 배수가 아닌 번호들

상태 분석:
  ❌ 핫/중립/콜드 분석: 미출현 주기별 번호 분류
  ❌ 미출현 그룹 (gap groups): 장기 미출현 번호 추적

특수 분석:
  ❌ 9궁 분석 (9-palace): 45개 번호를 9개 존로 나누어 분석
  ❌ 로또용지: 저장된 조합 시트 점수 평가

고급 기능:
  ❌ 필터 조합 추천: 12개 필터의 최적 조합
  ❌ 모델별 필터 선호: 각 모델이 선호하는 필터 범위
```

## 사용자 요구사항

### 명시된 요구사항
```
"4배수, 5배수 배수외 핫,중립, 콜드 분석, 미출현 그룹,
9궁, 로또용지 등등은 어디에 있는거야?
커스텀분석은 왜 안하는거야?"
```

**해석:**
1. **배수 필터**: mul4, mul5, non-multiple 분석 필요
2. **상태 분석**: 미출현 기간(gap)별로 번호를 hot/neutral/cold로 분류
3. **미출현 그룹**: 특정 기간 이상 미출현한 번호들의 그룹화
4. **9궁 분석**: 1-45 번호를 3x3 격자로 나누어 분석
5. **로또용지**: 저장된 조합(lottery sheets)의 평가
6. **커스텀분석 강화**: 현재는 기본 필터만 추천, 더 심화된 분석 필요

## 확장 계획

### Phase 1: 추가 필터 구현 (2개 필터 + 1개 분류체계)

#### 1.1 mul4 필터 추가
**정의**: 4의 배수 개수 (4, 8, 12, 16, 20, 24, 28, 32, 36, 40, 44) = 11개 수
**범위**: 0~6 (최대 6개 포함 가능)
**용도**: 짝수 패턴 분석 (4배수는 모두 짝수)

**구현 위치**:
- `deep_analysis_v3.py` 라인 57: `"mul4": sum(1 for x in c_int if x % 4 == 0),`
- `get_model_filter_expectations()`: mul4 섹션 추가 (라인 300-313 근처)
- `recommend_filters_for_group()`: mul4 추천 로직 추가 (라인 450-500 근처)
- `ai_deep_learning.html`: 필터 라벨 추가

#### 1.2 mul5 필터 추가
**정의**: 5의 배수 개수 (5, 10, 15, 20, 25, 30, 35, 40, 45) = 9개 수
**범위**: 0~6 (최대 6개 포함 가능)
**용도**: 끝자리 0 또는 5 패턴 분석

**구현 위치**: 위와 동일

#### 1.3 Gap 기반 상태 분류 (Hot/Neutral/Cold)
**정의**:
```
Hot:       gap 0-2 (최근 3회 이내 출현)
Neutral:   gap 3-7 (최근 8-10회 범위 출현)
Cold:      gap 8-15 (최근 15-20회 범위 미출현)
DeadCold:  gap 16+ (20회 이상 미출현 = 부활 시점 근처)
```

**추가 필터들**:
- `hot_count`: Hot 상태 번호 개수 (추천: 2~3개)
- `cold_count`: Cold 상태 번호 개수 (추천: 1~2개)
- `deadcold_count`: DeadCold 상태 번호 개수 (추천: 0~1개)

**구현 위치**:
- `deep_analysis_v3.py` 라인 160: `get_number_status()` 함수 추가
- 각 번호별 gap 계산 후 상태 할당
- 필터로 통합

### Phase 2: 9궁 분석 추가

#### 2.1 9궁 영역 정의
```
영역 배치:
  ┌──────┬──────┬──────┐
  │ 1-5  │ 6-10 │11-15 │  (상단, 수)
  ├──────┼──────┼──────┤
  │16-20 │21-25 │26-30 │  (중단, 화)
  ├──────┼──────┼──────┤
  │31-35 │36-40 │41-45 │  (하단, 토)

  - 예상 개수 (각 0~1개 = 최대 9개, 실제 6개이므로 일부 필터)
```

### Phase 3: 미출현 그룹 분석

#### 3.1 Gap 기반 그룹화
```python
def get_gap_groups(history: list) -> dict:
    """번호를 gap 범위별로 그룹화"""
    return {
        "hot": [번호들],        # gap 0-2
        "active": [번호들],     # gap 3-7
        "cooling": [번호들],    # gap 8-15
        "cold": [번호들],       # gap 16-25
        "deadcold": [번호들]    # gap 26+
    }
```

#### 3.2 권장 구성
```
이상적 구성: 2 hot + 2 active + 1 cooling + 1 cold
- Hot 2개: 최근 출현한 번호들로 모멘텀 유지
- Active 2개: 활발한 구간 번호로 안정성
- Cooling 1개: 점진적으로 자주 나올 번호
- Cold 1개: 극도로 미출현한 번호 = 부활 가능성
```
