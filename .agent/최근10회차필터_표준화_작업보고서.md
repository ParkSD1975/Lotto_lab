## 📊 표준 사양 개요

### 🎨 버튼 디자인 (Tailwind CSS)
- **기본 상태:** `bg-gradient-to-r from-blue-500 to-indigo-600` (파란색)
- **활성화 상태:** `bg-gradient-to-r from-purple-500 to-purple-700` (보라색)
- **아이콘:** `auto_fix_high` (스파클링 아이콘)
- **ID:** `recent10FilterBtn` (버튼), `recent10FilterText` 또는 `recent10BtnText` (텍스트)

### ⚙️ 핵심 로직 (applyRecent10Filters)
1.  **토글 관리**: 버튼의 클래스(`from-purple-500`)를 기반으로 현재 상태를 감지하여 켜기/끄기 수행.
2.  **데이터 분석**: 최근 10회차 당첨 회차의 분석 지표(개수, 비율, 값 등)를 수집하여 Min/Max 범위를 추출.
3.  **필터 자동 입력**: 추출된 범위를 리스트 상단의 필터 입력 창(Input, Checkbox 등)에 자동 주입.
4.  **필터 활성화**: `applyFilterCheck` (또는 유사 ID) 체크박스를 `true`로 설정하여 실시간 필터 적용.
5.  **하이라이트**: `highlightStartRound` 전역 변수를 설정하여 리스트 내 최근 10회차 행을 보라색(`row-highlight`)으로 강조.
