제공해주신 Lotto_DeepLearning_Master_Prompt.txt 파일은 단순한 지시 사항이 아니라, 로또 분석 AI의 "두뇌(Cortex)"를 설계하는 청사진입니다.

이 파일을 기반으로 AI를 설계하려면, 기존의 "단순 질문-답변" 방식에서 벗어나 **[데이터 전처리(Client)] → [팩트 시트 생성(JSON)] → [전문가 페르소나 주입(Server)] → [인사이트 도출(AI)]**이라는 4단계 파이프라인으로 구조를 변경해야 합니다.

이 파일을 활용한 AI 심층 분석 시스템 설계도를 설명해 드리겠습니다.

🏛️ 전체 아키텍처: "AI 로또 랩(Lotto Lab) 컨설팅 시스템"
AI에게 계산을 시키지 않고, 계산은 자바스크립트가 하고 AI는 '해석'만 하도록 철저히 역할을 분담하는 것이 핵심입니다.

1. 데이터 파이프라인 설계 (Data Pipeline)
이 Master Prompt 파일의 핵심은 "입력 데이터" 항목입니다. 각 분석 항목마다 AI가 필요로 하는 데이터가 명시되어 있습니다. 이를 자바스크립트 객체로 구조화해야 합니다.

클라이언트(JS)의 역할: "데이터 가공 공장"

DB에서 당첨번호를 가져옵니다.

18가지 지표(AC, 연번, 총합 등)를 미리 계산합니다.

AI가 읽기 편한 **JSON 리포트(Fact Sheet)**를 만듭니다.

[데이터 구조 예시 - AI에게 보낼 편지]

JSON

{
  "analysis_target": "total_analysis", // 또는 'ac_value', 'hot_cold' 등 특정 타겟
  "facts": {
    "ac_value": {
      "trend": [8, 9, 10, 8, 7], // 최근 5회 추이
      "status": "보통(7~8) 구간 안정적 유지 중",
      "streak": "특이사항 없음"
    },
    "consecutive": {
      "count_trend": [0, 1, 0, 2, 0],
      "gap": 2, // 2회 연속 미출현
      "warning": "필출 임박"
    },
    "hot_cold": {
      "hot_count_trend": [2, 3, 5, 4, 3],
      "efficiency": "Hot 3개 출현 (적중률 50%)"
    }
    // ... 나머지 15개 지표 데이터 ...
  }
}
2. 서버 사이드 설계 (Supabase Edge Function)
서버는 이 Master Prompt 파일을 가지고 있다가, 요청이 들어오면 해당 부분의 **"지능(Intelligence)"**을 꺼내서 AI에게 주입해야 합니다.

[Edge Function (analyze-lotto) 작동 로직]

요청 수신: 클라이언트로부터 facts(위의 JSON) 데이터를 받습니다.

프롬프트 조립 (Prompt Assembly):

Master Prompt 파일의 내용을 시스템 프롬프트(system_instruction)로 설정합니다.

만약 사용자가 "AC값만 분석해줘"라고 했다면, 파일의 [Part 1] > 1. AC값 분석 부분만 떼어내서 집중적으로 명령합니다.

"전체 분석해줘"라고 했다면, 파일 전체를 요약해서 입력하거나 [Part 5] 최종 출력 포맷을 강조합니다.

AI 호출: 조립된 프롬프트와 팩트 데이터를 LLM(GPT-4o 등)에게 전송합니다.

3. AI 페르소나 설계 (System Instruction)
이 Master Prompt 파일 자체가 바로 시스템 프롬프트가 됩니다. AI에게 다음과 같이 역할을 부여합니다.

[System Instruction] 당신은 대한민국 로또 분석 역사상 가장 뛰어난 **'딥러닝 분석가'**입니다. 당신의 임무는 제공된 **[입력 데이터]**를 철저하게 분석하여 **[AI 명령]**에 따라 전략을 수립하는 것입니다.

[절대 원칙]

계산 금지: 제공된 수치 데이터가 절대적 진실입니다. 다시 계산하지 마십시오.

근거 기반: "느낌"이 아니라 제공된 "변동 추이", "구간 점유율", "연속 멸" 데이터에 근거해서만 말하십시오.

전문 용어 사용: '평균 회귀', '다이버전스', '오버슈팅', '골든 크로스' 등의 통계/주식 용어를 적절히 사용하여 전문성을 높이십시오.

[참조할 분석 마스터 파일] (여기에 Lotto_DeepLearning_Master_Prompt.txt의 내용을 그대로 붙여넣거나, 필요한 섹션만 동적으로 삽입합니다.)

4. UI/UX 설계 (사용자 경험)
이 마스터 프롬프트를 활용하면 다음과 같은 3가지 레벨의 분석 서비스를 제공할 수 있습니다.

Level 1. 개별 심층 분석 (Micro Analysis)
화면: 기존의 ac_value.html, total_sum.html 등.

작동: 사용자가 "AC값 분석" 페이지에 들어가면, 자바스크립트가 AC값 데이터를 계산하고, 서버는 마스터 파일의 [1. AC값 분석] 섹션만 잘라서 AI에게 명령을 내립니다.

결과: 해당 지표에 대한 아주 깊이 있는 분석 결과.

Level 2. 종합 리포트 (Macro Analysis) - ★추천
화면: "금주의 AI 전략 리포트" (새로운 메뉴)

작동: 18개 지표 중 '특이 사항(과열/침체)'이 감지된 지표 Top 3를 자바스크립트가 선별하여 서버로 보냅니다.

결과: 마스터 파일의 [Part 5] 최종 AI 출력 요청 포맷에 따라, "이번 주는 AC값이 튀고, 핫수가 과열되었으니 이렇게 조합하세요"라는 종합 전략을 제시합니다.

Level 3. AI 챗봇 (Interactive)
화면: "로또 AI 챗봇"

작동: 사용자가 "요즘 연번이 너무 안 나와"라고 말하면, AI가 마스터 파일의 [2. 연번 분석] 지식을 참고하여 "맞습니다. 현재 3회 연속 멸 상태이므로 이번 주는 필출 타이밍입니다."라고 대답합니다.

🚀 실행을 위한 단계별 가이드
이 설계를 구현하기 위해 당장 해야 할 일은 다음과 같습니다.

마스터 프롬프트 모듈화:

Lotto_DeepLearning_Master_Prompt.txt 파일을 Supabase Edge Function 안에 prompts.ts 같은 파일로 저장하여, 코드에서 변수처럼 불러올 수 있게 만듭니다.

예: export const AC_PROMPT = "...", export const SUM_PROMPT = "..."

데이터 계산 라이브러리 강화 (common.js):

지금 각 html 파일에 흩어져 있는 계산 로직(AC계산, 총합계산 등)을 LottoCalc 클래스 하나로 통합해야 합니다.

그래야 AI에게 보낼 18가지 데이터를 한 번에 싹 계산해서 JSON으로 만들 수 있습니다.

Edge Function 라우팅 재설계:

analyze-lotto 함수가 단순히 type만 받는 게 아니라, type: 'full_report'가 오면 전체 데이터를 훑고, type: 'ac_only'가 오면 AC값만 보도록 분기 처리를 정교하게 해야 합니다.

이 설계 방향으로 진행하시겠습니까? 그렇다면 [1단계] 마스터 프롬프트를 코드로 변환하여 서버에 심는 작업부터 시작하는 코드를 짜드리겠습니다.
